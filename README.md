# Python Web Development Bootcamp

## Description

This bootcamp is designed to teach programming concepts and problem-solving skills from a developer's perspective throughout the entire software development lifecycle, from the initial idea to project organization and implementation. Participants will also learn how the Internet works and how to build web applications using the **Django** framework, enabling them to use **Python** confidently and develop projects that serve both individuals and communities.

---

## Objectives

* Learn the fundamentals of using the **Command Line Interface (CLI)** to interact with the operating system.
* Master **Git** for version control and project management.
* Learn how to use **GitHub** for hosting repositories and collaborating on projects as part of a team.
* Gain a solid understanding of the **Python** programming language and use it effectively.
* Understand the fundamentals of the Internet and how the Web works.
* Build web pages using **HTML** and style them with **CSS**.
* Master the **Django** framework for developing web applications.
* Use **ORM (Object-Relational Mapping)** to interact with databases.
* Learn user authentication and identity management.
* Implement user permissions, authorization, and access control.
