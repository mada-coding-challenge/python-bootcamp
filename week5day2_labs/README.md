# Week 5 - HTML Labs

This folder contains HTML labs completed during Week 5. The labs focus on learning basic HTML structure and elements.

## First Lab

In the first lab, we learned how to create a simple HTML page using:

* Headings
* Paragraphs
* Links
* Images
* Email input fields

## Second Lab

In the second lab, we created two pages:

* A course page
* A profile page

We learned how to:

* Link between HTML pages
* Add images
* Create ordered and unordered lists
* Use headings and paragraphs
* Add a button to go back to the previous page

## Commands Learned

Start a simple local server:

```bash
python3 -m http.server
```

Open the local server:

```text
http://localhost:8000
```

Send a POST request using `curl`:

```bash
curl -X POST https://httpbin.org/post -d "name=aly"
```

Make a request to a website using `curl`:

```bash
curl https://wikipedia.com
```

Make a request to a website that doesn't exist using `curl`:

```bash
curl https://example.com
```
